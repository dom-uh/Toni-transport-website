# Toni's Transport Website

A responsive transportation and dispatch service website built from scratch using HTML and CSS.

## About The Project

This project is a website created for Toni's Transport to showcase their services, company information, and provide an easy way for customers to contact or book services.

## Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
- Google Fonts

## Features

- Responsive design for mobile, tablet, and desktop screens
- Mobile navigation menu
- Hero section with call-to-action buttons
- Services section
- About section
- Customer testimonials
- Contact section
- WhatsApp booking integration
- CSS animations and hover effects

## What I Learned

While building this project, I improved my understanding of:

- Writing semantic HTML
- Creating layouts with Flexbox
- Using media queries
- Working with CSS variables
- Making websites responsive
- Adding animations and interactive elements

## Development Process

I built this website from scratch by writing the HTML structure and CSS styling myself. I focused on creating a professional design, improving responsiveness across different devices, and making the website easy for users to navigate.
